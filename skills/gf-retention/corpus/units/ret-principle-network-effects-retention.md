**Principle — a user connected to others retains far better than a user alone.**

When a product's value rises with the people a user is connected to — teammates, collaborators,
followers, shared data — each connection raises both the value of staying and the cost of leaving.
Connected users are among the stickiest cohorts in almost every product that has a social or
collaborative dimension, because churning now means leaving **other people** and shared context
behind, not just a tool. Balfour's framing treats this engagement/retention core as the real growth
engine; classic network-effect theory (value scaling with connected nodes) is the why.

**How to apply.** Identify whether the product has a latent network (teammates, shared workspaces,
social graph, shared content) and make reaching it part of the path to value — getting a second user
in, sharing a workspace, connecting to a colleague. Measure retention of **connected vs solo** users;
if connected users retain markedly better, closing the gap (getting more users connected) is a
high-leverage retention play.

**When it applies.** Products with any multi-user, collaborative, or social dimension. Genuinely
single-player tools don't have this lever — don't manufacture a fake one.

**Caution (ethics).** Encourage **real, wanted** connections — never coerce invites, spam a user's
contacts, or gate core value behind forcing others in (classic viral dark patterns, documented not
prescribed). Respect contact-list consent and privacy law. Pairs with
[[ret-tactic-collaboration-invites]] and [[ret-principle-stored-value-switching-costs]].
