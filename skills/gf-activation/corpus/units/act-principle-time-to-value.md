**Principle — shorten time-to-value by designing around the aha moment.**

Activation hinges on the user reaching first real value (the "aha moment") as fast as
possible. Define activation as a specific, observable first-value event — not signup —
then remove everything between signup and that event. The sooner value lands, the more
likely the user persists to habit.

**How to apply.** (1) Identify the aha event empirically — the early action most
correlated with week-N retention (see `time_to_activation`, `w1_retention`). (2) Measure
steps/time from signup to it. (3) Cut or defer every step not on the path to it.

**When it applies.** Strongest for self-serve PLG where the user onboards alone. Less
load-bearing where a human (sales/CS) drives first value.

**Caution.** "Magic number" examples (e.g. "7 friends in 10 days") are illustrative, not
universal — the aha event must be derived from *this* product's data, never borrowed.
